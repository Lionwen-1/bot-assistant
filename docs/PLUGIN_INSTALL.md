# 安装与更新本地插件

bot助手 0.8.0 起可在“项目运维 → 插件”中选择一个本地 AstrBot 插件源码文件夹并安装到当前项目。本机免 Docker、本机 Docker 和远程 SSH 三种模式使用相同的校验与备份规则。

## 使用方法

1. 准备名称形如 `astrbot_plugin_example` 的插件源码文件夹。
2. 确认文件夹根目录包含 `main.py` 和 `metadata.yaml`，且 `metadata.yaml` 的 `name` 与文件夹名一致。
3. 在插件页点击“安装/更新本地插件”，选择该文件夹并核对确认框。
4. 安装成功后程序只重启 AstrBot，不重启任何 NapCat/QQ 账号。原版本会保存在当前项目的 `backups/` 目录。

## 安全与格式边界

- 只接受小写字母、数字和下划线组成的 `astrbot_plugin_*` 目录名。
- 只读取 `.py`、`.json`、`.yaml`、`.yml`、`.txt`、`.md`、`.html`、`.css` 和 `.js` UTF-8 文本文件。
- 忽略隐藏文件与 `__pycache__`，拒绝符号链接、绝对路径和目录穿越。
- 最多 120 个文件；单个文件不超过 300 KiB；总文本不超过 1.5 MiB。
- 客户端和目标项目都会检查文件清单；所有 Python 文件在落盘前进行语法编译检查，但不会执行。
- 不自动运行或安装 `requirements.txt`。确需第三方依赖时，请先审查来源，再通过 AstrBot 官方插件管理流程安装。

## 更新与回滚

更新时，现有插件目录会先原子移动到带时间戳的备份目录，再用已校验的新目录替换。若 AstrBot 重启失败，程序恢复旧目录并再次尝试启动 AstrBot；失败的新版本保留在同一备份目录的 `failed/` 下，便于排查。

该功能用于维护自己信任的插件源码，不会判断插件运行时行为是否安全。安装前仍应审查代码，不要安装来路不明的插件。
