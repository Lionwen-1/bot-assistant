## 申请前必须由权利人核对

1. **权利人身份与归属**：个人的证件姓名或单位全称、证件材料；如有委托开发、合作开发、职务开发或转让，需要相应的合同及权属证明。GitHub 昵称 `Lionwen-1` 不能代替法定身份信息。
2. **日期与发表状态**：实际开发完成日期、首次发表日期（如已发表）以及与版本 V0.7.1 对应的代码状态。不能仅用 Git 提交日期代替正式申报事实。
3. **原创性和第三方边界**：确认提交的源程序确属申请人享有权利的部分；不提交 AstrBot、NapCat、QQ 等第三方程序或其原始素材。
4. **当前表格与提交方式**：在中国版权保护中心系统填写官方申请表，上传或提交其当前要求的材料。不要把身份证明、签章或完整登记材料上传到 GitHub。

## 本地生成的草稿材料

在仓库根目录，用安装了 `reportlab` 的 Python 执行（首次可先运行 `python -m pip install reportlab`）：

```powershell
python scripts/prepare_copyright_materials.py
```

输出位于被 Git 忽略的 `output/pdf/`：源程序前后各连续 30 页的**排版草稿**与完整的软件使用说明书 PDF。脚本只选取本项目原创 Python 源码，生成文件清单与 SHA-256；不会打包个人配置或登录数据。

按登记办法，通常需提交申请表、源程序与一种文档的鉴别材料、身份及权属证明。程序和文档超过 60 页时，一般取前后各连续 30 页；不足 60 页时提交全部。除特定情况外，程序每页不少于 50 行、文档每页不少于 30 行。上述 PDF 是准备稿，最终分页、纸张、签章与在线表单要求需在提交时对照官方系统复核。
