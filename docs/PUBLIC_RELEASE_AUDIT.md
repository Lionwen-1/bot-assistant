旧私有仓库的部分提交作者元数据含个人 QQ 邮箱。公开仓库没有继承这些提交或旧标签；首次提交使用 GitHub 的匿名邮箱。旧仓库继续保持私有。

## 当前发布内容

- 源码和文档未发现真实 QQ 号码、API Key、SSH 私钥、服务器公网地址或个人电脑用户目录；测试中的账号和密钥均为示例值。
