# bot助手多账号连接与 AstrBot 项目运维软件 V0.7.1 使用说明书

本说明书介绍 bot助手的安装、运行、账号管理、Bot 设置和项目运维。软件面向在自己的 Windows 电脑或 Linux Docker 服务器上管理 AstrBot 与 NapCat QQ 机器人的用户。项目由 Lionwen-1 维护；正式软件著作权申请中的权利人名称以申请人证件和权属材料为准。

## 1. 软件概述

bot助手是 Windows 桌面程序，以账号卡片显示 QQ 登录状态，并提供 AstrBot 项目运维入口。程序支持三种连接模式：本机免 Docker、本机 Docker、远程 SSH。不同模式可以分别保存连接资料。账号卡片按已添加的 QQ 号数量显示，掉线账号仍保留，方便单独恢复。

软件的目标是让使用者在一个窗口完成部署引导、扫码登录、账号状态检查、模型与角色配置入口、可选语音设置、日志和备份查看。它不预置任何个人模型密钥，也不自动赋予非管理员修改思维强度的权限。

## 2. 运行环境与组件

客户端运行于 Windows，便携版 `BotAssistant.exe` 不要求使用者额外安装 Python。首次本机免 Docker 部署会从官方地址下载 AstrBot Desktop、NapCat Shell 和腾讯 QQ；这些第三方组件不包含在本项目的 EXE 中。本机 Docker 模式要求 Docker Desktop 运行 Linux 容器；远程 SSH 模式要求自己的 Linux 服务器具备 Python 3.9+、Docker Engine、Compose 和 SSH 私钥。

用户应为新建项目选取空目录，并确保可用磁盘空间与网络连接。首次下载完成后，实际聊天还依赖用户配置的模型 API、QQ 扫码登录和 AstrBot 平台连接。第三方组件与账号使用条件由各自提供者规定。

## 3. 首次启动与连接设置

双击 `BotAssistant.exe` 打开主窗口。进入“连接设置”，选择本机免 Docker、本机 Docker 或远程 SSH。免 Docker 模式选择新的空目录，填写 AstrBot 控制台密码、模型 API 地址、模型名、API Key、角色提示词及可选语音参数，然后按向导下载与部署。Docker 模式选择本机 Docker 项目；远程模式填写服务器地址、SSH 用户和本机私钥路径并核对服务器指纹。

连接资料按模式保存在本机用户配置目录。远程模式只保存私钥路径，不复制私钥内容。切换模式不会删除其他项目的账号数据。若连接失败，先检查所选模式、项目目录和服务器或 Docker 状态，再查看界面错误提示。

## 4. 添加 QQ 账号与扫码

在主窗口点击“添加账号”，输入 QQ 号码和昵称。程序检查重复号码，并为新号码建立独立的 NapCat 运行与持久化目录。成功添加后，卡片会显示该号码的昵称、头像、状态和取码入口。获取二维码后，用手机 QQ 扫码并确认登录。

二维码只对应所选账号。二维码过期或账号掉线时，在该账号卡片点击“获取登录码”。程序先检查状态和旧码时效；确需新码时只处理所选账号。状态尚不明确时不会贸然重启。QQ 登录成功并不必然表示 AstrBot 已连接；应继续检查 AstrBot 日志中的 OneBot 适配器状态。

账号菜单可修改昵称或移除账号。移除新建账号会停止其进程或容器并从列表删除，登录数据目录默认保留。重新添加同号账号可尝试复用已有登录数据。对已接管的原有容器，移除只取消 bot助手清单中的接管关系，不删除原容器。

## 5. Bot 设置

点击“Bot 设置”进入项目设置。使用者可填写自己的模型 API 与密钥，选择模型，编辑角色提示词，并按需启用语音识别和语音回复。密钥保存在使用者选择的 AstrBot 项目中；桌面摘要仅显示不含密钥的状态。对于现有项目，也可通过入口打开 AstrBot 官方控制台完成高级设置。

同一 AstrBot 项目的 QQ 账号默认共享项目模型和角色。若需要不同账号使用不同角色或模型，应在 AstrBot 控制台建立相应配置与路由。修改配置后应核对服务状态和实际消息回复。

## 6. 思维强度

在“Bot 设置 → 调节思维强度”中首次启用组件，再选择 QQ 平台和档位。支持的 DeepSeek 模型可设为关闭、低、高、最高；默认高档。首次启用会短暂重启 AstrBot，不重启 NapCat。保存档位后从该账号的下一条消息起生效，其他账号保持原设置。

AstrBot 管理员还可在对应 QQ 会话中发送“把思考强度调低”“把思考强度调到最高”“关闭思考”或“现在思考强度是多少”。程序以本地规则识别这些短句并检查管理员权限；普通成员不能更改。更换基础模型后需要重新启用组件，当前不支持的模型会在窗口显示原因。

## 7. 项目运维

点击“项目运维”查看服务状态、日志、备份、非敏感配置预览与插件清单。重启服务只作用于用户明确选择的服务。备份包含配置、数据库和 QQ 登录目录，可能含密钥，应存放在受保护的位置。远程模式的备份留在服务器项目目录，本机模式留在所选项目目录。

需要修改插件运行状态、更新插件或编辑 AstrBot 的高级配置时，打开 AstrBot 官方控制台。远程控制台通过临时 SSH 隧道访问；本机控制台使用回环地址。bot助手不开放公网 NapCat 管理端口，也不把第三方组件打包到本项目发布包中。

## 8. 常见故障与处理

安装文件下载失败时，检查网络与磁盘空间，校验失败的文件不应运行。腾讯 QQ 安装程序签名核验失败时停止部署。项目目录已有文件时另选空目录。面板端口占用时在连接设置中修改端口。二维码过期时只在对应账号重新获取。QQ 显示在线却不回复时，检查 AstrBot OneBot 连接、模型 API 地址和密钥，以及模型服务自身是否可用。

重启程序后看不到账号时，核对是否选择原项目目录，并检查项目的 `bot-assistant/accounts.json`。远程连接失败时核对服务器指纹、SSH 私钥和 Docker 权限。不要把 API Key、QQ 登录资料或完整备份贴进公开 Issue。
